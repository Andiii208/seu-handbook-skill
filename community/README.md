# community/ · 同学投稿材料区

这个目录放《大学生手册》之外、由同学投稿的材料——学校官网不公开或不易检索、但本科生确实需要的文件（各学院细则、专业培养方案、往年通知与办事模板、往年的口径说明等）。

手册的整理内容在仓库根目录的 `references/`（校级规章全文）和 `data/`（数值速查表）。**本目录的投稿材料不是学校印发的手册内容**：引用时必须注明"同学投稿、非官方"，并提示以学校正式文件和当年通知为准。

## 目录约定

```
community/
└── <主题>/                      # 小写英文连字符，如 tuimian-xize、peiyang-fangan
    └── <材料名>/                # 建议 <单位>-<材料>-<年份>，如 cs-tuimian-xize-2025
        ├── README.md           # 必填：来源、年份、适用范围等（字段见下表）
        └── <材料文件>           # .md/.txt 转写优先；原件可保留，亦可只留转写
```

## 每份材料必填的 README 字段

| 字段 | 说明 |
|---|---|
| 材料名称 | 全称，与文件内容一致 |
| 来源 | 哪个渠道拿到的（学院通知群、教务处网页、纸质件拍摄等） |
| 年份/版本 | 印发或获取时间，并注明核对状态（如"2025 年 9 月版，未见更新"） |
| 发布单位 | 学校部门或学院 |
| 适用范围 | 哪些年级、专业、学院适用 |
| 投稿人 | GitHub ID 或"匿名" |
| 脱敏说明 | 做过哪些处理（删电话、遮姓名等）；未脱敏须说明原因 |

以上均为**同学投稿的手册外材料**，非学校印发的手册内容。每份材料目录内的 `README.md` 记录了
来源、年份、适用范围与脱敏说明；引用时须连同这些信息一并给出，并提示以学校正式文件和当年通知为准。

投稿方式见仓库根目录的 [CONTRIBUTING.md](../CONTRIBUTING.md)；不想走命令行，直接用 GitHub 的
"材料投稿" issue 模板贴文件或链接。

## 红线

- 他人隐私必须脱敏：学号、电话、证件号、成绩单、"姓名 + 成绩"组合；
- 涉密、注明限定扩散的材料，不收；
- 来源说不清、合法性存疑的，先开 Issue 问，别直接投；
- 材料权利归原单位/原作者；本目录是非官方的学习检索用汇编，收录不代表学校立场。
