## 为什么值得收录

手册 `references/10-tuimian.md`（推免工作实施办法）只给校级原则，并明确"具体推荐条件……以学生推免
当年学校发布的正式文件为准"。本材料正是这类**当年文件**，给出可核对的硬门槛：

- 必修+限选课平均学分绩点（**按首修成绩计算**）≥ 3.0 **或** 专业排名前 40%；
- CET-4 ≥ 520 或 CET-6 ≥ 430 或 TOEFL ≥ 100 或 IELTS ≥ 7（单项不低于 6.0）；英语专业 TEM-4 ≥ 70；
- 研究生支教团推免专项：有不良记录者**一票否决**。
