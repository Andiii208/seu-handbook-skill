# 金标准题（验收用）

验收方法：让 Agent 只依据本仓库（references/ + data/ + sources.md + SKILL.md）回答下列问题。
每题检查三点：**结论正确**、**引用正确（规章名 + 条号）**、**没有编造**。含 4 道"手册没有"的边界题，正确答案必须是指引渠道而非给答案。

**可机跑部分**：A—F 各区末尾标注 `[机跑]` 的行，其"期望结论要点"里的关键数值已由
`tools/check.py` 的"引用内容一致"项对着 `references/` 原文自动校验（见该脚本 docstring
的变异测试说明）。未标注的行考的是边界行为与口径完整性，仍需人工跑。
