# 手册文本清洗规范（所有 references/*.md 生产必读）

## 任务
把 `/tmp/seu_hb/v2/chunks/<docid>.txt` 中的 OCR 文本清洗、结构化，写成
`references/<docid>.md`（相对仓库根目录）。

输入是"先左栏后右栏"阅读序的 OCR 文本（每个 PDF 页 = 手册两个页码的横展，
左栏=偶数手册页，右栏=奇数手册页）。chunk 文件里会混入**上一篇的结尾**和**下一篇的开头**，
必须按派工单给出的起止标记切除，只保留本篇规章的正文。

## 输出格式（严格遵守）
1. YAML frontmatter（字段见下），
2. `# 规章全称`（H1），
3. `> **要点速览**` 引用块：3–6 条，每条必须以条款号结尾，如"（第X条）"，内容必须出自本篇正文，
4. 正文：章标题用 `## 第X章 XXX`（原文无章名的_file_可省）；每条以 `**第X条** ` 开头单独成段；
   条款内的（一）（二）列表按原文逐行保留；表格转成 Markdown 表格，表后补一行"边界说明"（区间含不含端点、n 的含义等）；
   段内原本换行的中文要接成自然段，不要保留 OCR 硬换行。

frontmatter 模板：
```
---
source: 2025年大学生手册（东南大学校长办公室编，2025年8月）
doc: <规章全称>
handbook_pages: "<起始-结束手册页码>"
pdf_pages: "<PDF 页码>"
effective: <执行年级/生效时间，从正文摘录；没有则写"见正文">
owner: <解释单位，从正文"授权……负责解释"摘录>
refs: [本篇正文中引用到的其他规章名，用《》书名号去掉，逗号分隔]
topics: [5-10 个中文主题词]
---
```

## 清洗规则
1. **删噪声**：页脚页码行（形如 `= 002`、`—037 =`、`008 三`）、空行压缩、封面角标。
2. **OCR 错字修复**（按上下文判断，不要盲替；读不通的对照渲染图 `/tmp/seu_hb/pages/pg-NNN.png` 修正）：
   - 人学→入学；竟赛→竞赛；韵→的（获得韵成绩→获得的成绩）；钓→的；惠有→患有；
   - 修谈→修读；上还→上述；准子→准予；，予→予以；域写→填写；"学分前1/2"→"学分的 1/2"；
   - 東南/東→东；眚类怪字按上下文还原；体育课罗马数字（口/皿/罒/山 等）按"体育 I、II、III、IV、V、VI"还原。
3. **数字与符号**：0/O、1/l、5/S 混绕按语义还原；全角括号差异统一为（ ）《 》；
   英文术语（SCI/SSCI/EI/CSCD/CSSCI/SRTP/CCF/A&HCI/KPI/SEU 等）保留；
   明显的英文残片碎片（如 `S1502`、`UNIVE`、孤立字母行）删除。
4. **表格数值**：与渲染图逐值核对，一个数字都不许改错；核对不了的标 `<!-- 待核 -->` 并汇报。
5. **不改写、不删减正文内容**：只修错、去噪、调结构。原文语义一律保留，包括"本办法/本条例/本规定"的自指。
6. 存疑且无法确认的地方：保留最接近原文的读法，在文件末尾用 `<!-- 存疑：... -->` 注明。

## 验收标准（DoD）
- 本篇第一条到解释条完整、条号连续无跳号（原文本身跳号的除外，需在存疑注释说明）；
- 无残留 OCR 错字、无页码脚注、无相邻规章的溢出文字；
- 表格与渲染图一致；
- frontmatter 各字段已填；
- 产出文件即 `references/<docid>.md`，用 Write 工具创建。
