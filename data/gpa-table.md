# 成绩等级与学分绩点对应表

> 源自《东南大学全日制本科学生学分制管理办法》第七条（手册 052 页）。详细规则见 `references/14-xuefenzhi.md`。

## 成绩等级与学分绩点

| 成绩符 | 成绩分 | 绩点 |
|---|---|---|
| A+ | 100—96 | 4.8 |
| A | 95—93 | 4.5 |
| A- | 92—90 | 4.0 |
| B+ | 89—86 | 3.8 |
| B | 85—83 | 3.5 |
| B- | 82—80 | 3.0 |
| C+ | 79—76 | 2.8 |
| C | 75—73 | 2.5 |
| C- | 72—70 | 2.0 |
| D+ | 69—66 | 1.8 |
| D | 65—63 | 1.5 |
| D- | 62—60 | 1.0 |
| F | ＜60 | 0 |

边界说明：
- 区间两端点均含（如 95—93 含 93 和 95），相邻档端点无重叠无空隙；F 档不含 60 分。
- 60 分（或五级记分制"及格"）及以上方可取得该课程学分，并根据成绩等级确定学分绩点。
- 实践环节与考查课成绩"优、良、中、及格"的绩点分别与 A、B、C、D 对应，即 4.5、3.5、2.5、1.5。
- 毕业论文（毕业设计）等实践环节不记入平均学分绩点计算。

## 两种平均学分绩点（14-xuefenzhi 第八、九条）

| 类型 | 用途 | 计算范围 |
|---|---|---|
| 首修平均学分绩点 | 评奖评优、选拔优秀类排名 | 所学必修课、限选课（成绩以百分制或五级计分制记载）的首修成绩 |
| 总平均学分绩点 | 授予学位审核 | 学生所属专业指导性教学计划中规定所学必修课、限选课（成绩以百分制或五级计分制记载）的学分数×绩点之和 ÷ 规定时间内所学必修课、限选课的学分数之和 |

公式注意：原文把"**指导性教学计划中规定**"和"**百分制或五级计分制记载**"限定在**分子**，"规定时间内"只修饰**分母**。任选课、通过制记载的课程是否计入，按此口径判断。

## 民族特长生的绩点算法（03-minzu，自 2023 级起执行）

单独编班教学（数学类、物理类、计算机程序设计类、英语类）的课程，与普通生算法不同：

- 专业分流：单独编班教学课程成绩**乘 0.8 系数**后计算首修课程平均分（第二条第（三）项）；
- 评奖评优：单独编班教学课程成绩**乘 0.8 系数**后，以对应学分绩点计算首修平均学分绩点（第二条第（四）项）；
- 授予学位审核：单独编班教学**已获得学分**的课程**不参加**总平均学分绩点计算（分子、分母都不算）；**未获得学分**的课程在计算总平均学分绩点时，分子中该课程学分绩点为"0"、分母为课程学分数（第二条第（五）项）；
- 单独编班教学课程成绩以实得成绩记载，所获学分计入学籍审核学分和毕业审核学分（第二条第（二）项）。

## 关键分数线速查

| 事项 | 门槛 | 依据 |
|---|---|---|
| 取得课程学分 | 60 分（及格）及以上 | 学分制办法第七条 |
| 授予学士学位 | 平均学分绩点 ≥ 2.0 且达到培养方案全部要求 | 学位授予办法第四条 |
| 校长奖学金 | 平均学分绩点 ≥ 3.5（或 3.0—3.5 破格） | 校长奖学金办法第一条 |
| 三好学生 | 学年绩点 3.0 及以上、无不及格课程 | 三好评选办法第一条 |
| 三好学生标兵 | 绩点 4.0 及以上 | 三好评选办法第二条 |
| 国家奖学金 | 上一学年成绩排名本专业前 10%（或 10%—30% 破格） | 国奖办法第四、五条 |
| 国家励志奖学金 | 上学年成绩排名本专业前 50% | 励志办法第三条 |

注意：补考、重修成绩不参与校长奖、课程奖评选，也不参与免研排名、评优排名等选拔优秀类排名（学籍管理规定第十条）。
