# 校园生活高频规则速查表

> 源自手册各生活类规章。全文见 `references/41-gongyu.md`、`01-xueji.md`、`46-pingjiao.md`、`42-tushuguan.md`、`47-shiyanshi.md`、`45-shoufei.md`、`40-zhengjian.md`、`16-tiyu.md`。

## 一、请假

| 情形 | 审批 |
|---|---|
| 实习、军训、社会调查等活动期间 | 带队教师批准 |
| 一天及以上至一周以内 | 学院审批 |
| 一周以上至一个月以内 | 学院审批同意后报学生处审批 |
| 晚归、夜不归宿、夜不归校、夜间关门后外出 | 履行请假手续或备案 |
| 一学期累计病、事假 | 不得超过一个月 |

因病请假须附医院证明，因事请假须附有关说明。未按规定办理请假手续或不遵守校纪造成人身伤害、意外事故的，一切责任由当事者自负（学籍规定第七条）。

## 二、宿舍（公寓）

除注明外均依据 `references/41-gongyu.md`。

| 事项 | 规则 | 依据 |
|---|---|---|
| 门禁 | 每日 6:00 开门、24:00 关门 | 第二十四条 |
| 熄灯 | 本（预）科公寓周日至周四 23:00 熄灯；周五、周六及其他节假日不熄灯；研究生公寓不熄灯 | 第二十四条 |
| 晚归/未归 | 24:00 至次日 6:00 进入公寓视为"晚归"；至次日 6:00 仍未进入视为当日"未归"；24:00 后不得随意外出，晚出晚归须登记备案 | 第二十四条 |
| 身份认证 | 进出须身份认证，失败须登记；钥匙、一卡通不得转借，不得私自换锁加锁 | 第二十五条 |
| 访客 | 登记后方可进入宿舍区域，须在 21:30 前离开；不得留宿非本宿舍成员；接访员有责任提醒访客遵守规定 | 第二十六条 |
| 床位 | 公寓和床位统筹安排，不得擅自调整、占用、转让、出借、出租；调整须网上申请、学校审批 | 第十四、十八条 |
| 退宿 | 退宿手续办结后三天内搬离；申请入住/调整/退宿审批通过后七天内办理手续 | 第十九、二十一条 |
| 爱心宿舍 | 行动不便、伤病可申请暂住，一般不超过 3 个月 | 第二十二条 |
| 校外住宿 | 原则上应办理退宿；全日制本科生申请校外住宿需家长同意；延长学习年限本科生原则上不提供住宿 | 第十六、十九条 |
| 水电 | 水电计量收费，从一卡通扣费；退宿前须结清，未结清不予办理退宿 | 第三十七条 |

**违章电器**（收缴代管；有病等特殊情况凭学院盖章签字病例申请审批后可使用；依据第三十条）：
1. 800W 以上超功率电器（吹风机、热水壶除外）；
2. 无自动断电保护装置电器；
3. 无国家 3C 认证电器；
4. 热得快、电炉、电热毯、电热水器、电熨斗、烘干器、烘鞋机等易引发火灾电器，电饭锅、微波炉、电磁炉、烤箱、空气炸锅、电煮锅等炊具；
5. 洗衣机、电冰箱、制冰机、电视机等；
6. 含大电池的电器设备（电动车电瓶、充电平衡车等）；
7. 其他存在安全隐患的电器。

## 三、评教

依据 `references/46-pingjiao.md`（第二条组织管理）。

- 每学期开展学生评教，分过程性评教和期末评教；期末评教须在开放期间对所选课程教师进行评价，**完成评教后方能实时在线查看课程成绩**。
- 不允许代替他人或找他人代为评教。
- 教师可查询本人评教成绩和匿名学生主观评语；学生可查询自己的课程评教情况及分析数据。

## 四、图书馆

依据 `references/42-tushuguan.md`（第一至四条）。

- 凭本人有效校园卡刷卡（人脸识别）进出馆，严禁使用他人证件入馆；校园卡不得转借。
- 阅览区及书库内禁止用餐、吃零食、喝用无盖器皿盛装的有色饮料；严禁占座。
- 离馆时如遇门禁系统报警，须自觉配合检查；未办理借阅手续图书不得带出馆；学生离校前须归还图书。

## 五、实验室安全

依据 `references/47-shiyanshi.md`（第三条）。

- 进实验室开展课程实验和科研训练活动前，必须通过学校或所在院系组织的**实验室安全考试**；科研训练活动（含学科竞赛、毕业/学位论文研究、大创项目等）需履行《实验室安全准入报告》制度。
- 实验须遵守安全操作规程、正确佩戴防护用品；不得擅自脱岗；实验后清理场地、切断电源气源水源、熄灭火种。
- 危险物品（剧毒、易制毒/易制爆、麻醉药品、病原微生物、实验动物、放射性同位素、特种设备等）须遵守国家法规和学校规定、做好台账。
- 违规按《东南大学学生违纪处分条例》给予通报批评或警告至开除学籍处分；涉嫌犯罪移送司法机关。

## 六、缴费与退费

依据 `references/45-shoufei.md`（收费退费规则）+ `references/01-xueji.md` 第五条（暂缓注册）。

- 学费通过东南大学缴费平台（http://caiwuchu.seu.edu.cn）缴纳。
- **两条路径别混淆**：“缓缴学费”是收费办法第四条的资助程序（困难学生经学生处/研究生院办理）；“暂缓注册”是学籍规定第五条的程序（因故不能如期注册时履行）。不注册不能参加教学活动、不能使用教学资源；不按时注册超过两周又未办暂缓注册的，予以退学处理。手册未写缓缴的具体期限，能拖多久以学生处当年办理指南为准。
- 学分制收费采用预收结算制：在校所修正常选课总学分 ≤ 专业培养方案要求毕业最低学分 + 5，免收加修学费；超出部分按学分收费标准计收；重修、辅修按实际报名选课每学年结算。
- 提前毕业少收一年/半年专业学费；不及格补考一次免费，补考后仍不及格须交该课程学分学费重修。
- 免修：带实验、实践环节的课程按该课程学分学费标准缴纳 1/3 学分学费，其他课程不收。
- 退费：第一学期开学一个月内批准退学等终止学业的全额退还专业学费，超过一个月退还 50%，第二学期内不退还；休学可比照退学退费，休学期间不交纳专业学费和学分学费；开学第三周内退选课程免收学分学费。
- 住宿费按实际住宿情况缴纳；延期离校按月计缴住宿费。

## 七、体育与体测

依据 `references/16-tiyu.md`（第二条体育课程与体测综评、第三条良好标准、第八条跑步锻炼、第十一条交流认定）。

| 事项 | 规则 |
|---|---|
| 体育课学分 | 体育课程为必修课计 3 学分：一二年级 4 个学期各 0.5 分（及格得 2 学分），三年级体育 V、VI 各 0.5 分（及格得 1 学分） |
| 跑步锻炼 | 一二年级每学期跑步出勤最低 45 次合格，否则体育成绩不及格（记 59 分）；三、四年级可申请重修；每学期 50 次至满勤给予该学期体育总成绩 2—5 分奖励 |
| 旷课 | 三次迟到或早退记一次旷课；迟到早退超 15 分钟记旷课一次；一学期旷课两次以上或累计缺课四次及以上，体育课程必须重修 |
| 体测综评 | 大学 1—3 年级平均成绩 ×50% + 大学 4 年级成绩 ×50% ≥50 分，不合格按结业或肄业处理。注意：《国家学生体质健康标准》的具体评分标准（各项目多少分算合格/良好）不在手册内，需查教育部发布的标准 |
| 评三好 | 当年度体育课程成绩达良好（80 分）及以上方可参加"三好学生"评选 |
| 保健课 | 体弱多病或慢性病学生原则上第八周前申请，经校医院保健科证明、保健课教师认定，可修读体育保健课，通过跑步锻炼加分，当学期最高 80 分 |
| 免修 | 校运动队学生训练期间可免上体育课，成绩由教练员评定，须完成体测 |

## 八、证件与户政

依据 `references/40-zhengjian.md`。

- 学生证、校徽、校园卡注册后发给；离校时学生证件全部上交（毕业时学生证盖注销章，校徽可留存）。
- 学生证不得转借；转借造成不良影响的给予警告以上处分；私自涂改证件除停止享受火车票优惠一年外并按违纪处分条例处分。
- 证件丢失：填写补办学生证申请表（教务处网页下载），经学院负责人审核签署意见后到相关部门补办，按不超过工本费 2 倍收费；不得持两套证件。
- 寒暑假返家探亲可凭学生证享受购票优惠，须如实填写家庭地址，变更持证明办理。

## 九、因公出国（境）

依据 `references/48-chuguo.md`。

- 学生在"学生因公出国（境）申报审批系统"申请，经院（系）、部处、基层党委和分管外事校领导同意，由国际合作处（港澳台办公室）下发任务批件；**不得事后申报**。
- 需持因私证照并自行办理签证；赴台湾申请按国家规定报江苏省台湾事务办公室审批。
- 在外期间严格遵守外事纪律；不得延长停留天数（超期费用不予报销）；严禁前往未经审批的其他国家。
- 赴国（境）外期间医疗费用按国家公费医疗管理规定不予报销，出境前需办理相关保险。
