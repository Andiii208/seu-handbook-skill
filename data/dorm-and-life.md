# 校园生活高频规则速查表

> 源自手册各生活类规章。全文见 `references/41-gongyu.md`、`01-xueji.md`、`46-pingjiao.md`、`42-tushuguan.md`、`47-shiyanshi.md`、`45-shoufei.md`、`40-zhengjian.md`、`16-tiyu.md`、`48-chuguo.md`、`44-wangluo.md`、`43-chubanwu.md`。

## 一、请假

| 情形 | 审批 |
|---|---|
| 实习、军训、社会调查等活动期间 | 带队教师批准 |
| 一天及以上至一周以内 | 学院审批 |
| 一周以上至一个月以内 | 学院审批同意后报学生处审批 |
| 晚归、夜不归宿、夜不归校、夜间关门后外出 | 履行请假手续或备案 |
| 一学期累计病、事假 | 不得超过一个月 |

因病请假须附医院证明，因事请假须附有关说明。未按规定办理请假手续或不遵守校纪造成人身伤害、意外事故的，一切责任由当事者自负（01-xueji 第七条）。

## 二、宿舍（公寓）

除注明外均依据 `references/41-gongyu.md`（第十四至二十二条、第二十四至二十七条、第三十条、第三十七条）。

| 事项 | 规则 | 依据 |
|---|---|---|
| 门禁 | 每日 6:00 开门、24:00 关门 | 第二十四条 |
| 熄灯 | 本（预）科公寓周日至周四 23:00 熄灯；周五、周六及其他节假日不熄灯；研究生公寓不熄灯 | 第二十四条 |
| 晚归/未归 | 24:00 至次日 6:00 进入公寓视为"晚归"；至次日 6:00 仍未进入视为当日"未归"；24:00 后不得随意外出，晚出晚归须登记备案 | 第二十四条 |
| 身份认证 | 进出须身份认证，失败须登记；钥匙、一卡通不得转借，不得私自换锁加锁 | 第二十五条 |
| 访客 | 登记后方可进入宿舍区域，须在 21:30 前离开；不得留宿非本宿舍成员；接访员有责任提醒访客遵守规定 | 第二十六条 |
| 床位 | 公寓和床位统筹安排，不得擅自调整、占用、转让、出借、出租；调整须网上申请、学校审批 | 第十四、十八条 |
| 退宿 | 退宿手续办结后三天内搬离；申请入住/调整/退宿审批通过后七天内办理手续 | 第十九、二十一条 |
| 爱心宿舍 | 行动不便、伤病可申请暂住，一般不超过 3 个月 | 第二十二条 |
| 校外住宿 | 原则上应办理退宿；全日制本科生申请校外住宿需家长同意；延长学习年限本科生原则上不提供住宿 | 第十六、十九条 |
| 水电 | 水电计量收费，从一卡通扣费；退宿前须结清，未结清不予办理退宿 | 第三十七条 |

**违章电器**（收缴代管；有病等特殊情况凭学院盖章签字病例申请审批后可使用；**为违章电器充电即视为使用违章电器**；依据 `references/41-gongyu.md` 第三十条）：
1. 800W 以上超功率电器（吹风机、热水壶除外）；
2. 无自动断电保护装置电器；
3. 无国家 3C 认证电器；
4. 热得快、电炉、电热毯、电热水器、电熨斗、烘干器、烘鞋机等易引发火灾电器，电饭锅、微波炉、电磁炉、烤箱、空气炸锅、电煮锅等炊具；
5. 洗衣机、电冰箱、制冰机、电视机等；
6. 含大电池的电器设备（电动车电瓶、充电平衡车等）；
7. 其他存在安全隐患的电器。

## 三、评教

依据 `references/46-pingjiao.md`（第二条组织管理、第三条信息反馈；评教依托“网上评教（本科）”平台）。

- 每学期开展学生评教，分过程性评教和期末评教；期末评教须在开放期间对所选课程教师进行评价，**完成评教后方能实时在线查看课程成绩**。
- 不允许代替他人或找他人代为评教。
- 教师可查询本人评教成绩和匿名学生主观评语；学生可查询自己的课程评教情况及分析数据。

## 四、图书馆

依据 `references/42-tushuguan.md`（第一至七条）。

- 凭本人有效校园卡刷卡（人脸识别）进出馆，严禁使用他人证件入馆；校园卡不得转借。
- 阅览区及书库内禁止用餐、吃零食、喝用无盖器皿盛装的有色饮料；严禁占座，离馆时带清个人物品。
- 借阅须凭本人校园卡办理借阅手续；续借、预约和委托借还遵守《图书借阅规则》《图书馆图书委托借还服务工作规程》；未办理借阅手续的图书不得带出馆；学生离校前应归还图书并办完手续。
- 合理使用图书馆购买的电子资源（详见《关于电子资源版权公告》）；违反规章制度的按《图书馆违章处理工作规则》处理。

## 五、实验室安全

依据 `references/47-shiyanshi.md`（第三条安全考试与准入报告、第五条实验过程规范、第七条危险物品、第十二条责任追究种类、第十三条处分档次、第十四条事故责任）。

- 进实验室开展课程实验和科研训练活动前，必须通过学校或所在院系组织的**实验室安全考试**；科研训练活动（含学科竞赛、毕业/学位论文研究、大创项目等）需履行《实验室安全准入报告》制度。
- 实验须遵守安全操作规程、正确佩戴防护用品；不得擅自脱岗；实验后清理场地、切断电源气源水源、熄灭火种、关好门窗。
- 危险物品（剧毒、易制毒/易制爆、麻醉药品、致病性病原微生物、实验动物、放射性同位素、射线装置、行车、叉车、压力容器和其他特种设备等）须严格遵守国家法律法规和学校规定，采取可靠防范措施，做好详细台账记录。
- 违规按《东南大学学生违纪处分条例》给予通报批评，或警告至开除学籍处分；责任追究种类可单独使用，也可合并使用（第十二条）；涉嫌犯罪的依法移送司法机关（第十四条）。

## 六、缴费与退费

依据 `references/45-shoufei.md`（收费退费规则）+ `references/01-xueji.md` 第五条（暂缓注册）。

- 学费通过东南大学缴费平台（http://caiwuchu.seu.edu.cn）缴纳。
- **两条路径别混淆**：“缓缴学费”是 45-shoufei 第四条的资助程序（困难学生经学生处/研究生院办理）；“暂缓注册”是 01-xueji 第五条的程序（因故不能如期注册时履行）。不注册不能参加教学活动、不能使用教学资源；不按时注册超过两周又未办暂缓注册的，予以退学处理（01-xueji 第二十七条（一）6）。手册未写缓缴的具体期限，能拖多久以学生处当年办理指南为准。
- 正常选课学费按学年收取，毕业离校前按在校所修总学分与培养方案毕业最低学分的**差值**结算：所修正常选课总学分 ≤ 最低学分 + 5，免收加修学费；超出部分按规定学分收费标准计收（第六条（一））。重修、辅修按实际报名、选课每学年结算（第六条（二））。**自 2019 级起执行，"新生新办法、老生老办法"**（第五、六条）。
- **大类分流结算（预收结算制）**：按大类招录的新生入学第一年预收学费，一年后分流时按分流后专业的收费标准收取学费并结算第一年预收部分——分流后标准**高于**原预收的不补收少交部分，**低于**原预收的退还多交部分（调整第二年学费）（第五条）。
- 延长学习年限学生按学分制收费办法交纳相关费用，按**实际选课情况每学年结算学费**（11-yanchang 第三条；45-shoufei 第七条注明延长学习年限不按学籍异动处理）。
- 提前毕业少收一年/半年专业学费；不及格补考一次免费，补考后仍不及格须交该课程学分学费重修。
- 免修：带实验、实践环节的课程按该课程学分学费标准缴纳 1/3 学分学费，其他课程不收。
- 退费：第一学期开学一个月内批准退学等终止学业的全额退还专业学费，**原则上**超过一个月退还 50%，第二学期内不退还；休学可比照退学退费，休学期间不交纳专业学费和学分学费；开学第三周内退选课程免收学分学费。
- 住宿费按实际住宿情况缴纳；延期离校按月计缴住宿费。

## 七、体育与体测

依据 `references/16-tiyu.md`（第二条体育课程与体测综评、第三条良好标准、第四条免上体育课、第五条保健课、第八条跑步锻炼、第十一条交流认定）。

| 事项 | 规则 |
|---|---|
| 体育课学分 | 体育课程为必修课计 3 学分：一二年级 4 个学期各 0.5 分（及格得 2 学分），三年级体育 V、VI 各 0.5 分（及格得 1 学分）（16-tiyu 第二条） |
| 跑步锻炼 | 一二年级每学期跑步出勤最低 45 次合格，否则体育成绩不及格（记 59 分）；跑步锻炼不合格者**须**于三、四年级申请重修，达到 45 次即可获得相应学期体育课程成绩，成绩性质记为重修；每学期 50 次至满勤给予该学期体育总成绩 2—5 分奖励。因伤病住院不能参加者，出院一周内携材料到体育系处理（16-tiyu 第八条） |
| 旷课 | 三次迟到或早退记一次旷课；迟到早退超 15 分钟记旷课一次；一学期旷课**三次及以上**（原文“两次以上（不含两次）”）或累计缺课四次及以上，该学期体育课程必须重修；因特殊疾病或其他不可抗拒因素经体育系审核批准后可不重修（16-tiyu 第七条） |
| 体测综评 | 大学 1—3 年级平均成绩 ×50% + 大学 4 年级成绩 ×50% ≥50 分，不合格按结业或肄业处理（16-tiyu 第二条）。注意：《国家学生体质健康标准》的具体评分标准（各项目多少分算合格/良好）不在手册内，需查教育部发布的标准 |
| 评三好 | 当年度体育课程成绩达良好（80 分）及以上方可参加"三好学生"评选（16-tiyu 第三条） |
| 保健课 | 体弱多病或慢性病学生原则上第八周前申请，经校医院保健科证明、保健课教师认定，可修读体育保健课，通过跑步锻炼加分，当学期最高 80 分（16-tiyu 第五条） |
| 免修 | 校运动队学生训练期间可免上体育课，成绩由教练员评定，须完成体测（16-tiyu 第四条） |

## 八、证件与户政

依据 `references/40-zhengjian.md`。

- 学生证、校徽、校园卡注册后发给；离校时学生证件全部上交（毕业时学生证盖注销章，校徽可留存）。
- 学生证不得转借：未造成不良影响的，视情节及危害程度给予**批评教育或处分**（40-zhengjian 第四条）；**造成不良影响的给予警告以上处分**（37-weiji-chufen 第二十一条（一））。私自涂改证件除停止享受火车票优惠一年外，并按违纪处分条例处分（40-zhengjian 第八条）。
- 证件丢失：填写补办学生证申请表（教务处网页下载），经学院负责人审核签署意见后到相关部门补办（40-zhengjian 第六条）；补办费用按**不超过证、卡工本费的 2 倍**收取（45-shoufei 第十四条（二））；不得持两套证件（40-zhengjian 第七条）。
- 寒暑假返家探亲可凭学生证享受购票优惠，须如实填写家庭地址，变更持证明办理。

## 九、因公出国（境）

依据 `references/48-chuguo.md`。

- 学生在"学生因公出国（境）申报审批系统"申请，经院（系）、部处、基层党委和分管外事校领导同意，由国际合作处（港澳台办公室）下发任务批件；**不得事后申报**。
- 需持因私证照并自行办理签证；赴台湾申请按国家规定报江苏省台湾事务办公室审批。
- 在外期间严格遵守外事纪律；不得延长停留天数（超期费用不予报销）；严禁前往未经审批的其他国家。
- 赴国（境）外期间医疗费用按国家公费医疗管理规定不予报销，出境前需办理相关保险。

## 十、校园网络

依据 `references/44-wangluo.md`（第三条负责单位、第四条禁止危害网络、第五/七至九条账户口令、第十二条软件安全、第十六条代理与 Email 服务器）。

- 校园网系统的安全运行和设备管理维护由**网络与信息中心**负责；任何单位和个人未经其同意不得擅自安装、拆卸或改变网络设备。
- 校园网各类服务器中的帐户和口令为个人用户所有；用户账户密码须妥善保管，**不得向任何单位和个人提供**。
- 不得利用各种网络设备或软件技术从事用户帐户及口令的侦听、盗用活动（视为侵犯网络用户权益）；不得以任何方式试图登陆进入校网主、辅节点、服务器进行修改、设置、删除；不得盗窃、破坏网络设施。
- 不得利用联网计算机从事危害校园网及未授权（含 CERNET 及其他互联网）服务器、工作站的活动；严禁在校园网上使用来历不明、可能引发病毒传染的软件。
- 未经校网络安全领导小组批准，各单位一律不得开设代理服务器、Email 服务器。

## 十一、学生出版物

依据 `references/43-chubanwu.md`（第四、五条创办审批、第十条重新登记）。

- 学生出版物实行**创办申报审批制度**，向校团委申请注册登记并经**校党委宣传部批准**后方可出版；面向全校师生的由校团委指导管理，面向班级、学院的由学院团委指导管理。
- 内容不得与党的基本路线相抵触，不得捏造歪曲事实，不得对他人进行人身攻击、侮辱和诽谤。
- 按管理机关规定的发行方式发行；如需张贴，经批准后到指定地点张贴。
- 登记在册的学生出版物应于**每年十月**向校团委申请重新登记；名称等重大事项变更须报校团委重新登记备案；停刊须办理停刊手续；不按规定重新登记或重新登记未获通过的，视为停刊，不得出版。
