# 学业关键规则与红线速查表

> 源自手册 A 部分学业类规章。全文见 `references/14-xuefenzhi.md`、`15-kaoshi.md`、`01-xueji.md`、`07-zhuanzhuanye.md`、`09-fenliu.md`、`10-tuimian.md`、`05-xuewei.md`。

## 一、学业红线（最重要）

| 情形 | 后果 | 依据 |
|---|---|---|
| 一学期获得学籍审核学分＜12 学分（可选学分≥12 学分时）；或可选学分＜12 学分时获得数＜可选 2/3 且 ≥1/2 | 退学警告，10 日内可申请退学试读（一学期，仅一次机会） | 学籍规定第二十六条 |
| 二年级结束累计学籍审核学分＜55 | 退学处理 | 学籍规定第二十七条 |
| 三年级结束累计＜90 | 退学处理 | 同上 |
| 五年制四年级结束累计＜130 | 退学处理 | 同上 |
| 第二次受到退学警告 / 未按期申请试读 | 退学处理 | 同上 |
| 不按时注册超过两周又未履行暂缓注册手续 | 退学处理 | 学籍规定第五条 |
| 休学期满超过两周未申请复学或复查不合格 | 退学处理 | 学籍规定第二十四条 |
| 未经批准连续两周未参加教学活动 | 退学处理 | 学籍规定第二十七条 |
| 一学期旷课累计 60 学时 | 开除学籍 | 违纪处分条例第二十四条 |
| 无故缺课累计超课程学时 1/3，或抽查旷课 3 次，或缺交作业 3 次 | 不得参加该课程期末考试，成绩记"缺考"、绩点 0、不予补考 | 学分制办法第十二条 |
| 自费留学 | 必须办理退学手续 | 学籍规定第三十条 |

## 二、考试与成绩

| 事项 | 规则 |
|---|---|
| 补考 | 仅限于当学期首修不及格；成绩以实得成绩记载并记"补"字；**不参与校长奖、课程奖评选，不参与免研/评优排名** |
| 重修 | 成绩记"重"字、按实得成绩计算绩点；实验类、实践类、体育、全校通识选修课等无补考 |
| 及格重修 | 75 分（含）以下及格课程可跟班重修一次，每学期允许申请不超过 2 门 |
| 缓考 | 因公、因病或其他不可抗拒情况，须考前申请，获批后在该课程再次开设学期参加考试 |
| 缺考 | 未申请缓考/缓考未准/擅自不考/迟到 15 分钟以上，期末成绩记"缺考"，不予补考 |
| 成绩复核 | 成绩公布后至下一学期开学两周内向学院教务助理申请 |
| 免修 | 免修考试成绩 75 分以上获准免修（记"免修"）；每学期免修课程原则上不超过 2 门；有实验环节的须补做实验及格 |
| 免听 | 学习基础好、自学能力强者可申请免听，但必须参加所有过程考核 |
| 作弊处理 | 该课程成绩记为无效，不予补考，并按违纪处分条例处分 |

## 三、转专业

- **时间与次数**：每学年组织一次，安排在春季学期；在校期间已成功转专业一次（新生二次选拔、大类分流、扶病/调整转专业不计入）不允许再转。
- **范围**：集中申请面向一、二、三年级学生（三年级仅可在**学院内**转）；转出学院不设绩点和比例限制，接收学院可设接收条件。
- **不予转专业情形**：入学未满一学期或已修满教学计划总学分 2/3 及以上或应退学；特殊招生形式录取有规定或约定的；其他经学校认定不符合条件的。
- **个别申请**：专长转专业（高中以来国际级或国家级权威竞赛一等奖及以上第一获奖人，或核心期刊独立/第一作者论文+三名教授推荐信）、政策转专业、扶病转专业、助学转专业、调整转专业。高考成绩原则上不得低于入学当年转入专业录取分数线；**高考文科类学生不能转入理工类专业**。
- 已获准转专业不得放弃；须完成原专业当学期已选课程考核；按转入专业教学计划审核毕业资格，原专业课程按"相近高要求替代低要求"认定。

## 四、大类分流

- 时间：一般安排在转专业工作结束之后，春季学期结束前完成。
- 对象：按大类招生的取得正式学籍新生 + 上一级保留入学资格未参与者 + 复学至该年级未参加过分流者 − 转专业转出 − 休学/退学等。
- 原则：生为首位、志愿优先、择优录取；综合测评成绩不能仅含课程成绩单项；第一志愿超额按综合测评成绩从高到低录取，不足则全员录取、从其他志愿递补。
- 志愿填报覆盖大类所含所有可选专业，放弃视同服从调剂。

## 五、推免（免试攻读研究生）

> 术语说明：手册原文有时写“免研排名”“免试推荐/免试推研”，均指推免（推荐优秀应届本科毕业生免试攻读研究生）。

- 基本条件：纳入国家普通本科招生计划的应届优秀全日制本科毕业生（不含第二学士学位学生）；无考试作弊、论文抄袭、虚报获奖等学术不端；无违法违纪和记过及以上处分记录；修完并通过前三年（五年制前四年）教学计划规定的所有课程。
- 综合成绩 = 课程成绩 + 综合能力成绩，其中**课程成绩权重不少于 80%**，综合能力成绩包括参军入伍服兵役、志愿服务、到国际组织实习、科研成果、竞赛获奖等，各项之和满分 100 分；同一方面有多项加分原则上只取一项。
- 取消资格情形：学术不端或其他严重影响公平公正行为；毕业时不能按时毕业或无法获得学士学位；未通过学院资格复审；专项计划推免生违反协议或不能胜任。
- 学校推免名单公示结束上报后不再受理放弃申请；私自放弃者将在个人档案中注明不诚信记录。
- 推荐工作一般每年 8—9 月执行，具体以当年学校正式文件为准。

## 六、毕业、结业与学位

| 事项 | 规则 |
|---|---|
| 毕业 | 规定年限内取得培养方案全部学分（必修、限选、任选、通识选修、课内外实践环节）+ 通过规定必修环节 + 体测合格 |
| 提前毕业 | 提前取得全部学分并通过必修环节，经分管教学副院长审批做毕业设计，学校审批后可提前毕业 |
| 结业 | 修完指导性教学计划规定内容、取得全部学分 90% 以上但未达毕业要求；因成绩结业可在最长学习年限内回校重修换发毕业证；受留校察看处分的毕业班学生作结业处理，解除处分后可换发 |
| 肄业 | 学满一学年及以上退学，发肄业证书 |
| 学位 | 平均学分绩点 ≥2.0 且达到培养方案各项要求；受记过或留校察看处分的毕业生解除处分后方可提交学位讨论申请；学术不端（代写、剽窃、伪造等）不授予或撤销学位 |
| 最长学习年限 | 标准学制 4 年/5 年；在校实际学习时间最长 6 年/7 年；最长学习年限 8 年/9 年（含休学和保留学籍）；累计休学不超过 2 年；延长学习年限最多两次且不超过标准学制加两年 |

## 七、选课与学分

- 选课分第一轮选课和第二轮补选、退选、改选；试听一周后可退选；开学两周后原则上不得变动。
- 选修人数少于 10 人的课程原则上停开（必修课、研讨课和规定必须开设的课程除外）。
- 每学期期末考试课程门数一般为 4—5 门。
- 学分换算：16 授课学时记 1 学分；讨论课、实践课程等 32 学时记 1 学分，或 1.5 周记 1 学分。
- 交流学习每学期至少完成对方高校对应培养方案不少于 15 学分课程学习（毕业班除外），"及格/通过"以上方可认定学分。
