# 违纪处分与申诉速查表

> 源自《东南大学学生违纪处分条例》《东南大学学生申诉实施办法》（手册 145—153 页）。全文见 `references/37-weiji-chufen.md`、`38-shensu.md`。

## 一、处分种类与期限

| 处分种类 | 期限 | 解除 |
|---|---|---|
| 警告 | 6 个月 | 期满自动解除 |
| 严重警告 | 6 个月 | 期满自动解除 |
| 记过 | 6 个月 | 期满自动解除 |
| 留校察看 | 12 个月 | 察看期内由所在院系考察；期满后本人书面申请，经院系及主管部门提出意见、报分管校领导批准后可解除 |
| 开除学籍 | — | 报江苏省教育厅备案（因政治问题开除学籍须报省教育厅审批） |

处分期限自作出处分决定之日起计算。解除处分后，学生获得表彰、奖励及其他权益不再受原处分影响。

**对评奖评优的影响**：受警告、严重警告、记过处分后 6 个月内，受留校察看处分后 1 年内，不具有申请"三好学生"等荣誉称号及奖助学金的资格。

**从重情形**：已受过处分或通报批评；对检举人、证人威胁打击报复；教唆胁迫诱骗指使他人违纪；策划或组织群体违纪或在共同违纪中起主要作用；确有违纪行为但拒不承认错误。

## 二、典型行为与处分档次（节选高频）

| 行为 | 处分档次 |
|---|---|
| 违反考场纪律 | 警告或严重警告 |
| 考试作弊 | 记过、留校察看直至开除学籍 |
| 考试作弊行为严重（代替他人考试/让他人代替自己考试/组织团伙作弊/使用通讯设备作弊等） | 开除学籍 |
| 一学期旷课累计达 60 学时 | 开除学籍 |
| 赌博（首次参与） | 警告或严重警告 |
| 屡次参与赌博 | 记过或留校察看；情节严重开除学籍 |
| 盗窃、诈骗、故意损毁公私财物 | 情节较轻严重警告及以下；情节严重记过或留校察看；违反治安管理规定性质恶劣或构成犯罪开除学籍 |
| 结伙斗殴或殴打他人 | 未动手但挑起事端：警告或严重警告；动手打人情节轻：警告或严重警告；情节严重：记过、留校察看直至开除学籍 |
| 在宿舍使用违章电器、违规使用明火等扰乱公共秩序 | 视情节警告、严重警告、记过、留校察看直至开除学籍 |
| 携带管制刀具/易燃易爆等危险品 | 严重警告以上；造成事故或有危险：留校察看或开除学籍 |
| 网络违纪（盗用账号、非法入侵、传播破坏性程序、传播违法信息等） | 视情节警告以上直至开除学籍；造成经济损失须赔偿 |
| 违反学术道德规范 | 视情节警告、严重警告直至开除学籍 |
| 违反学生公寓规范 | 视情节警告、严重警告直至开除学籍 |
| 违反治安管理规定受到处罚 | 治安警告或罚款：严重警告、记过；行政拘留：留校察看直至开除学籍 |
| 构成刑事犯罪被处刑罚 | 开除学籍 |
| 持有、吸食、贩卖毒品 | 开除学籍 |

注意：行为同时违反两条以上校纪，按较重处理；两人以上共同违纪按各自行为、情节、危害后果分别给予处分。处分决定前须书面告知学生事实、理由及依据，学生及其代理人可在收到告知书之日起 **5 日内**陈述申辩。

## 三、申诉时限链

| 步骤 | 时限 | 依据 |
|---|---|---|
| 收到处分决定书后向学校学生申诉处理委员会提出书面申诉 | **10 日内** | 申诉办法第七条 |
| 申诉处理委员会作出复查结论并告知申诉人 | 接到申诉书后 **15 日内**；情况复杂经批准可延长 **15 日** | 申诉办法第十一条 |
| 对复查决定不服，向学校所在地省级教育行政部门提出书面申诉 | 收到复查决定书之日起 **15 日内** | 申诉办法第十四条 |
| 省级教育行政部门处理并作出决定 | 接到书面申诉之日起 **30 个工作日**内 | 教育部 41 号令第六十二条 |

申诉范围：警告、严重警告、记过、留校察看、开除学籍等行政处分；取消入学资格、取消学籍、退学处理；法律法规规章规定可以申诉的其他处理决定。申诉期间不停止处分决定的执行。逾期未申诉视为放弃，不再受理。

**不予受理的情形**：申诉不在规定范围；未提交书面申诉书或材料不符合要求；未在规定时间内提交；撤回申诉后以相同理由再次申诉。

## 四、其他相关

- 考试违纪/作弊的课程成绩记为无效，不予补考（学籍管理规定第十一条）；学生处、研究生院按违纪处分条例给予相应处分。
- 结业生、毕业生回校参加考试发生违纪行为两次及以上或作弊及以上行为的，学校不再允许其回校参加所有考试。
- 学生证件（学生证、校园卡）转借、盗用、涂改、伪造的，视情节给予批评教育或处分。
- 非全日制学生、少数民族预科生的违纪处分参照《东南大学学生违纪处分条例》执行。
